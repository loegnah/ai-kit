# Archify

Create a source-grounded, reproducible diagram for design, review, or sharing. `/loegg archify [topic]` takes this path even for a small topic; `show-me` and other workflows can use the same procedure when warranted. If no topic is given, use the active topic or change.

## Prepare

1. Use the bundled Archify at [`vendor/`](./vendor/) next to this file (upstream `archify` 3.3.2, copied unmodified; `vendor/bin/archify.mjs` is the CLI). Read [`vendor/SKILL.md`](./vendor/SKILL.md) for type selection, authoring, and repair; this action sets the permissions and path rules. Never resolve Archify from `skill://archify`, `~/.agents`, `~/.claude`, or any other global or project install; never install or update it automatically. Refresh the bundle only on explicit request, by replacing `vendor/` with a fresh `npx -y skills@latest add https://archify.si --skill archify --agent codex --copy --yes` result from a scratch directory inside the repo, then updating `skills-lock.json`.
2. Reuse Node.js 18+ and Chrome/Chromium (`ARCHIFY_CHROME` can point to an installed executable). If a prerequisite is missing, or the requested scope is read-only, report the blocker. In an automatic invocation the caller can still give an inline explanation; do not call it an Archify result.

## Run and report

- Choose the diagram type from the question. Ground repository-backed diagrams in Archify's required evidence at a pinned revision. If the requested view depends on uncommitted changes, stop and explain the evidence limit rather than diagramming an older revision.
- Write only to the output folder chosen below and to `~/tmp/.archify/`. Resolve `~` to an absolute path first, and create the folder if it is missing.
- **Default output**: a fresh `~/tmp/.archify/<project>/<type>-<slug>-<timestamp>/` (`<project>` is the target project's directory name) for `candidate.json`, the standalone HTML, and verification receipts. Never write `.archify/` into the target project.
- **Docs output**: decide on your own, without asking, before the run. Use docs when the target project's `docs/` already roughly follows the [`../doc/SKILL.md`](../doc/SKILL.md) taxonomy (its targets or equivalents such as `docs/architecture/`) and nothing there objects: project instructions, a docs site with its own build or navigation, or generated docs. Otherwise keep the default output. Resolve the target with `../doc/SKILL.md` (project guidelines and existing `docs/` layout first), and state the chosen path in the report:
  - `architecture`, `class`, `erd`, `tree`, `dataflow`, `sequence`, `workflow`, `lifecycle` -> `design`; `timeline`, `waterfall`, PR review -> the matching existing `story/<story-dir>/` (default output when none matches); `explainer` -> `note` for a diagnosis or troubleshooting, else `design`. Never save Code Analysis to docs.
  - Put `candidate.json`, `<slug>.html`, its `.delivery.json` sidecar, and an optional exported `<slug>.svg` in `<target-dir>/diagrams/<slug>/`. Write or update `<target-dir>/<slug>.md` with the doc template, linking the HTML (embed the SVG when present) and stating the pinned commit.
  - Keep the slug stable and re-deliver in place on later runs; never add a timestamp folder under `docs/`. Send finalize receipts to the run's `~/tmp/.archify/` folder with `--out-dir`.
  - To save an earlier default-output result, re-run `finalize` from its candidate to the docs path; do not copy the HTML, because the delivery sidecar binds the absolute output path.
- Set `TMPDIR`, `TMP`, and `TEMP` to a fresh `~/tmp/.archify/.scratch-<timestamp>/` for the child process; on macOS also set `MAC_CHROMIUM_TMPDIR` there for Chrome's socket. Set `ARCHIFY_UPDATE_CHECK_DISABLED=1` to prevent the update lookup and cache. If the browser cannot run within the allowed write scope, report it as blocked. Remove only the scratch directory created for the run.
- Run the bundled `vendor/bin/archify.mjs` with Node from the target project using `finalize` and the selected quality profile. Pass `--repo-root` for repository-backed diagrams. Keep the candidate, HTML, and receipts for reproduction. Link them on success and distinguish automated browser checks from visual inspection. If a gate fails after Archify's focused repair steps, report the failed gate; do not present partial HTML as a verified result.
