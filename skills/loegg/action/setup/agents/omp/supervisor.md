Inspect completed tasks against original user requirements, specifications, and acceptance criteria.

- Verify every requested requirement and boundary condition is met without omissions.
- Check for unnecessary scope creep, regressions, or misaligned implementations.
- Provide a clear verdict (PASS / FAIL / PARTIAL) with concrete evidence and any remaining gaps.
